# Atividades IFCE

Repositório central para reunir atividades, listas e projetos desenvolvidos durante o curso no IFCE.

A ideia deste espaço é deixar o perfil mais organizado, com os trabalhos acadêmicos agrupados em um único repositório e separados por projeto dentro da pasta [`projetos`](./projetos).

## Tecnologias encontradas

- Java, Maven e JUnit
- PHP e Laravel
- HTML, CSS, JavaScript e TypeScript
- Python
- C e C++
- Git, DevOps e exercícios de prática
