# Atividades IFCE

Repositorio central para reunir atividades, listas e projetos desenvolvidos durante o curso no IFCE.

A ideia deste espaco e deixar o perfil mais organizado, com os trabalhos academicos agrupados em um unico repositorio e separados por projeto dentro da pasta [`projetos`](./projetos).

## Tecnologias encontradas

- Java, Maven e JUnit
- PHP e Laravel
- HTML, CSS, JavaScript e TypeScript
- Python
- C e C++
- Git, DevOps e exercicios de pratica
