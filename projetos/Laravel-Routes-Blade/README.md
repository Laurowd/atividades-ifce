# pw1-laravel-rotas-blade

Atividade da disciplina de Programação Web I - IFCE Campus Boa Viagem.

## Objetivo
Desenvolver um mini sistema utilizando o framework Laravel, aplicando o padrão MVC (Model-View-Controller), organização de rotas, agrupamento com prefixo, criação de controllers e views, uso de parâmetros na URL e reutilização de código com Blade.

## Estrutura do Sistema
- Rotas Principais (`/`, `/sobre`, `/contato`, `/login`)
- Grupo de Rotas com Prefixo `/app` (`/app/clientes`, `/app/fornecedores`, `/app/produtos`)
- Parâmetros via URL em fornecedores e produtos
- Uso de Blade Templates (`@extends`, `@include`, `@yield`, `@section`, `@if`, `@foreach`)
